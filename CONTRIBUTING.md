# Contributing

Glacier Relay is currently a research-stage project.

Before implementation, read the architecture, roadmap, ADRs, and research notes. Contributions should distinguish demonstrated behavior from hypotheses and should include reproducible evidence for claims about Glacier internals.

Do not submit proprietary IO Interactive code/assets, credentials, piracy-enabling material, or copied upstream code without preserving its license obligations and attribution.

Native changes should minimize the Glacier-facing surface. Higher-level changes must not introduce dependencies on raw Glacier pointers or memory layouts.
