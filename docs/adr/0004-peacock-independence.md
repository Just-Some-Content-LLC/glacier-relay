# ADR 0004 — Keep Peacock independent from the initial architecture

**Status:** Accepted.

Peacock solves WOA backend/service emulation. Glacier Relay's first problem is runtime observation/control and multi-instance coordination. No Peacock fork or translation is required for M0-M9.

Peacock remains valuable prior art and a potential future integration surface. Any future source reuse must be reviewed against its license and contribution/project policies.
